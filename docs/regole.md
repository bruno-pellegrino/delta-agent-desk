# Classification and escalation rules

## Categories

1. Baggage
2. Delays & cancellations
3. Booking & changes
4. Refunds & compensation
5. Service & experience
6. Praise
7. General info
8. Other

## Escalation

Escalation = **YES** if at least one applies:

| Rule | Trigger |
|---|---|
| E1 | Asks for money (refund, compensation, voucher, damages) |
| E2 | Requires access to the customer's booking, or contains personal data |
| E3 | Legal threat, media threat, or very strong anger |
| E4 | Health, safety, disability, minors |
| E5 | Urgent ongoing situation (stuck at airport, flight within hours) |
| E6 | Unintelligible or unclassifiable message |

Otherwise **NO**: the agent drafts a reply.
